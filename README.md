# Hello AI 🤖

A pretty simple dash style game where a cube jumps over rectangular obstacles.  
Built as a small experiment to explore AI-assisted development using OpenCode.  
The model used was GLM-5.3-Flash (free).

## Getting Started

```bash
npm run dev
```
